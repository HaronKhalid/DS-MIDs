Data Science & the lifecycle

What Data Science is, the steps of a project, and how to take a first look at data.

What is Data Science?

Data Science means getting useful insights from raw data. It mixes statistics, programming and domain knowledge.
  • Statistics: understand patterns and uncertainty.
  • Programming: collect, clean and analyse data at scale (Python, R, SQL).
  • Domain knowledge: know what the numbers mean for the real problem.

Exam definition: Data science is an interdisciplinary field that combines mathematics, statistics, computer science, artificial intelligence and domain expertise to extract meaningful insights and knowledge from raw, structured or unstructured data.

Examples: predicting student performance, detecting fraudulent bank transactions, recommending videos, predicting house prices.

Telling the roles apart (exam focus)

The value of all these roles is business insight from data.
  • Data Engineer builds infrastructure → data flows reliably.
  • Data Analyst describes what happened (reporting, descriptive analysis).
  • Data Scientist builds models and finds insight, often predicting what will happen.
  • ML Engineer turns a model into a working, monitored product.

Common mix-up: calling every data job “data scientist”. In real teams the roles overlap, but each has a main responsibility.

Big Data (the 5 Vs)

What makes data “big” and the five Vs that describe it.

What is Big Data?

Big Data = very large, complex, fast-growing or diverse datasets that traditional processing methods may struggle to handle.

It is not only about size. Data can also be big because it arrives very fast, comes in many forms or is hard to trust.

اردو مثالپانچ ملازمین کی تنخواہ 30، 32، 35، 36 ہزار اور مالک کی 400 ہزار ہو تو اوسط (mean) بہت بڑھ جاتا ہے مگر درمیانی قدر (median) تقریباً ٹھیک رہتی ہے۔ اس لیے تنخواہ کے لیے median بہتر ہے۔

Spread, range and outliers

Worked example with the scores 2, 4, 4, 4, 5, 5, 7, 9:

  1. Mean = (2+4+4+4+5+5+7+9) / 8 = 40 / 8 = 5
  2. Squared deviations: 9, 1, 1, 1, 0, 0, 4, 16 → sum = 32
  3. Variance = 32 / 8 = 4
  4. Standard deviation = √4 = 2
  5. Range = 9 − 2 = 7
The mean is sensitive to extreme values; the median is robust. An outlier is an unusual value: investigate it, do not delete it blindly.
Population variance divides by n (as in the lecture definition); when your data is only a sample, software often divides by n − 1.

Normal distribution and z-score

The normal distribution is the bell curve: 68% of data lies within 1 standard deviation of the mean, 95% within 2 and 99.7% within 3.

z-score = (x − mean) / SD: how many standard deviations a value is from the mean. A mark of 80 with mean 60 and SD 10 has z = 2.

اردو مثالکلاس کے نمبر عموماً گھنٹی کی شکل میں ہوتے ہیں: زیادہ تر طلبہ اوسط کے قریب اور بہت کم طلبہ بہت اوپر یا بہت نیچے۔

Hypothesis testing and the p-value

Steps: define H0 → define H1 → set alpha (0.05) → run the test → get the p-value → compare p with alpha → decision.
  • H0 (null): the default claim: no difference, no effect.
  • H1 (alternative): what you suspect instead.
  • Alpha (significance level): the cut-off, usually 0.05.
  • p < alpha → reject H0 (result significant). p ≥ alpha → fail to reject H0.
p-value = the probability of a result at least this extreme assuming H0 is true. It is not the probability that H0 is true, and “fail to reject” does not prove H0.
اردو مثالایک کمپنی کہتی ہے کہ اس کی ڈیلیوری اوسطاً 30 منٹ میں ہوتی ہے۔ ہم نمونہ لے کر دیکھتے ہیں؛ اگر p-value 0.05 سے کم آئے تو دعوے کے خلاف مضبوط ثبوت ہے۔

Correlation vs causation

Correlation r runs from −1 (perfect negative) through 0 (none) to +1 (perfect positive). It shows association, not cause.
|r|Strength
0.8 – 1.0very strong
0.6 – 0.8strong
0.4 – 0.6moderate
0.2 – 0.4weak
below 0.2very weak / none

Notes example: ice-cream sales and drowning both rise in hot weather: correlation exists, causation does not. Hot weather (a confounder) drives both.

اردو مثالگرمی میں آئس کریم بھی زیادہ بکتی ہے اور لوگ تیراکی بھی زیادہ کرتے ہیں، اس لیے ڈوبنے کے واقعات بھی بڑھتے ہیں۔ آئس کریم اور ڈوبنا ساتھ ساتھ بڑھتے ہیں (correlation) مگر ایک دوسرے کی وجہ نہیں (causation نہیں)۔

Probability and sampling basics

  • Probability measures how likely an event is, from 0 (impossible) to 1 (certain): P = favourable outcomes / all outcomes. Example: a fair die shows 4 with probability 1/6.
  • Population = everyone you want to know about. Sample = the subset you actually measure.
  • Common sampling methods: simple random (everyone has an equal chance), systematic (every k-th item), stratified (random from each group), cluster (randomly choose whole groups).
  • A biased sample (for example only one city) gives misleading results.

Classification metrics

How to check how well a classification model works: confusion matrix, accuracy, precision, recall and F1.

What is classification?

Classification is a supervised machine-learning task that predicts a categorical class or label.
  • Binary: two classes (spam / not spam).
  • Multiclass: more than two (cat / dog / bird).
  • Multilabel: one item can have several labels.

Examples: fraud / not fraud, positive / negative review, approved / rejected. The notes say metrics help us check how well the model works.

The confusion matrix: TP, TN, FP, FN

A confusion matrix compares actual classes with predicted classes. Read each term as: (was the model right?) + (what did it predict?).
TermMeaning (fraud example from your notes)
TP true positiveModel said “fraud” and it really was fraud ✔
TN true negativeModel said “no fraud” and it really was genuine ✔
FP false positiveModel said “fraud” but it was genuine. Also called Type I error (false alarm).
FN false negativeModel said “no fraud” but it was fraud. Also called Type II error (missed case).

We use TP = 40, TN = 45, FP = 5, FN = 10 (total 100) in all worked examples below.

اردو مثالفراڈ والا ماڈل: اگر اس نے اصلی فراڈ کو 'فراڈ' کہا تو یہ TP ہے۔ اگر اصلی لین دین کو 'فراڈ' کہہ دیا تو FP (جھوٹا الارم) ہے۔ اگر اصلی فراڈ کو 'ٹھیک' کہہ دیا تو FN (چھوٹ جانے والا کیس) ہے۔

Accuracy

Accuracy = (TP + TN) / (TP + TN + FP + FN): how many predictions were right in total (right / total).

Worked: (40 + 45) / (40 + 45 + 5 + 10) = 85 / 100 = 0.85 (85%).

Careful: on imbalanced data accuracy can mislead. If only 10 of 1,000 transactions are fraud, a model that always says “no fraud” is 99% accurate and catches nothing.

Precision

Precision = TP / (TP + FP): of all the “yes” predictions, how many were actually right.

Worked: 40 / (40 + 5) = 40 / 45 = 0.889.

Use it when: a false alarm is costly, like a genuine email being marked as spam. Goal: reduce false alarms.

Recall and specificity

Recall (sensitivity) = TP / (TP + FN): of all the actual “yes” cases, how many did the model catch.

Worked: 40 / (40 + 10) = 40 / 50 = 0.80.

Use it when: missing a real case is dangerous (disease, fraud). Goal: reduce missed cases.

Specificity = TN / (TN + FP) = 45 / 50 = 0.90: of all actual “no” cases, how many were correctly found.

اردو مثالاسپیم فلٹر میں اصلی ای میل کا اسپیم میں چلا جانا مہنگا ہے، اس لیے precision اہم ہے۔ بیماری کی اسکریننگ میں بیمار کا چھوٹ جانا خطرناک ہے، اس لیے recall اہم ہے۔

F1 score

F1 = 2 × (Precision × Recall) / (Precision + Recall): the harmonic mean, a balance of precision and recall.

Worked: 2 × (0.889 × 0.80) / (0.889 + 0.80) = 1.422 / 1.689 = 0.842.

Use it when both precision and recall matter. It is low if either one is low. (Notes: “jab precision dono important ho”.)

Overfitting & underfitting

Why a model can fail on new data, and how to tell what went wrong.

The big idea: generalisation

A model learns from training data, but its real job is to perform well on new data it has never seen. This ability is called generalisation. Overfitting and underfitting are two ways generalisation fails.

Underfitting

The model is too simple. It has not learned the pattern, so it performs poorly on both training data and new data.

Also called high bias. Causes: too few features, short training, strong regularisation, a model too simple for the pattern.

Overfitting

The model is too complex. It memorises the training data including its noise, so it looks excellent in training but performs poorly on new data.

Also called high variance. Causes: too complex a model, too many features, a small dataset, excessive training.

Good fit and the student analogy

Good fit: the model captures the true patterns and performs well on both training data and new data.
  • Underfitting = a student who barely studied.
  • Overfitting = a student who memorised last year's paper word for word.
  • Good fit = a student who understands the concepts and can solve any new question.
اردو مثالایک طالب علم نے پچھلے سال کا پرچہ رٹ لیا (overfitting): پرانے سوال ٹھیک مگر نیا سوال غلط۔ دوسرے نے بالکل پڑھا ہی نہیں (underfitting): ہر سوال غلط۔ تیسرے نے تصورات سمجھے (good fit): نیا سوال بھی حل کر لیتا ہے۔

Data cleaning

Data cleaning = detecting and correcting inaccurate, incomplete, inconsistent, duplicate or irrelevant data. Notes: fix weak or missing data; incorrect and duplicate values.
ProblemWhat to do
Missing valuesRemove, or impute (mean / median / mode) when justified
DuplicatesIdentify and remove repeated records
Incorrect data typesConvert to the right type (text → number, text → date)
Inconsistent valuesStandardise spelling, case, units, categories
OutliersDetect, then investigate: error or real value?
Invalid valuesCheck ranges and rules (impossible age)
Integration issuesResolve differences when combining sources
Exam focus: cleaning is not simply deleting bad rows. First understand why a value is missing, wrong or unusual.

Data manipulation

Manipulation = transforming and organising data so it can be analysed. Pandas is the most common Python library for it.
  • Filtering rows by a condition
  • Selecting or removing columns
  • Sorting values
  • Grouping and aggregation (sum, mean, count)
  • Merging / joining datasets
  • Reshaping data; changing data types
  • Creating calculated (derived) columns
import pandas as pd
df = pd.DataFrame({"city": ["Lahore", "Karachi", "Lahore"], "marks": [78, 91, 70]})
print(df.groupby("city")["marks"].mean())

Needs pandas installed. Output: Karachi 91.0, Lahore 74.0 (mean of 78 and 70).

Cleaning vs manipulation: cleaning fixes quality problems; manipulation reshapes data for analysis.

Data visualisation: choosing a chart

Visualisation = showing data in graphical form (charts, graphs) to communicate patterns, trends, distributions and relationships. Choose the chart by the question you are answering.
ChartBest used forExample
Bar chartComparing categoriesSales by product
Line chartTrends over timeMonthly revenue
Pie chartSimple part-to-wholeMarket share (few slices)
HistogramDistribution of a numerical variableAge distribution
Scatter plotRelationship between two numbersStudy hours vs marks
Box plotSpread and outliersSalary distribution
HeatmapMany values / correlations as coloursCorrelation matrix

Good practice: clear title, labelled axes, a legend when needed, readable scales and sensible colours. Avoid misleading charts (for example, a cut-off axis or a pie with many slices).

Glossary (search)

One-Page Cheat Sheet

1. Lifecycle

  • Problem → Acquire → Explore → Clean → EDA → Features → Model → Evaluate → Deploy → Monitor
  • EDA first checks: shape, info, describe, null check

2. Roles

  • Scientist: models + statistics (Python, R, SQL, TensorFlow)
  • Analyst: reports (Excel, SQL, Tableau, Power BI)
  • Engineer: pipelines (Spark, Hadoop, Airflow, Kafka)
  • ML Engineer: deploy (PyTorch, TensorFlow, Docker)

3. Big Data: 5 Vs

  • Volume = how much
  • Velocity = how fast
  • Variety = how many forms
  • Veracity = how trustworthy
  • Value = how useful

4. Data types

  • Structured: SQL tables
  • Semi-structured: JSON, XML
  • Unstructured: images, text, audio, video
  • Nominal: no order · Ordinal: order · Discrete: counted · Continuous: measured

5. Acquisition

  • Data = raw facts and figures
  • Primary: interview, survey, questionnaire
  • Secondary: repository, database, cloud
  • Check permission, privacy, quality, bias

6. Statistics

  • Mean = sum / count · Median = middle · Mode = most frequent
  • Range = max − min
  • Variance = average squared deviation · SD = √variance
  • z = (x − mean) / SD
  • Normal: 68 / 95 / 99.7 % within 1 / 2 / 3 SD
  • r = Cov(X,Y) / (sx·sy); correlation ≠ causation
  • Hypothesis: H0 → H1 → α=0.05 → test → p → compare → decide

7. Classification metrics

  • Accuracy = (TP+TN)/Total
  • Precision = TP/(TP+FP)
  • Recall = TP/(TP+FN)
  • Specificity = TN/(TN+FP)
  • F1 = 2PR/(P+R)
  • FP = Type I · FN = Type II
  • Example 40/45/5/10: acc 0.85, prec 0.889, rec 0.80, F1 0.842
  • Imbalanced data: do not trust accuracy

8. Over / underfitting

  • Underfit: train high error, test high error (high bias)
  • Overfit: train very low, test high, wide gap (high variance)
  • Good fit: both low and close
  • Fix underfit: more complexity / features
  • Fix overfit: simplify, regularise, more data, cross-validate

9. Tools and charts

  • NumPy numbers · Pandas data · Matplotlib/Seaborn charts · scikit-learn ML
  • Orange: visual, teaching · Weka: Java ML · Python: everything
  • Bar categories · Line trend · Pie part-to-whole · Histogram distribution · Scatter relationship · Box spread/outliers
